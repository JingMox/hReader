# @hreader/cli

`hr` — the standalone CLI for hReader single-file HTML documents: outline, read or patch one block, undo, normalize, serve, and export to print HTML / PDF / PNG.

Build from the repo root with `pnpm -C @hreader/cli build`; the entry point is `dist/cli.mjs` (exposed as `hr` when installed). Every command accepts `--json` for a machine-readable envelope.

## Environment variables

| variable         | effect                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `HREADER_HOME`   | relocates the **config root** — the parent of `.hreader/` (`permissions.json`, `daemon.json`), default `~/.hreader` under the real home. Applies wherever a command resolves `io.home`: `serve` (a `--home` flag wins when given), and the foreign-document permission lookup in `hr pdf` / `hr png`. Chrome children never inherit it — the spawned browser's own `HOME` is pinned to the passwd home, so this variable is the safe way to isolate config in tests and sandboxes (rewriting `HOME` instead stalls the browser's network stack). |
| `HREADER_CHROME` | path to a Chrome/Edge/Chromium binary for `hr pdf` / `hr png`; overrides the three standard probe paths                                                                                                                                                                                                                                                                                                                                                                                                                                          |

## Exit codes

This table is the written half of the external error contract, derived from the `HrErrorCode` union in `@hreader/core` and the `satisfies` table in `src/exit-codes.ts`: **a new code must be added in all three places (both files plus this table)** — `satisfies` only keeps the first two in sync. Exit-code semantics: `0` success / `1` business refusal / `2` usage error / `3` I/O / `70` internal error.

| code                                   | exit | when it happens (user's view)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| -------------------------------------- | ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `invalid_html`                         | 1    | the input is not a string, or injecting the theme style failed because the document has no `<head>`                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `no_article`                           | 1    | **the source document has no `<article>`** — nothing to export                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `empty_document`                       | 1    | **`<article>` exists but has no readable text once interactive UI is stripped** (must not be merged with `no_article`); zero-width characters `U+200B`/`U+FEFF`/`U+180E` are stripped before judging, otherwise a zero-width-only document would produce blank pages                                                                                                                                                                                                                                                                                            |
| `node_not_found`                       | 1    | three sources: ① the `data-hr-id` matches no node (the id does not exist); ② the selector hits a target that is **not addressable** (e.g. a `<span>` without `data-hr-id` cannot anchor a patch); ③ the grammar is legal but matches zero elements. All three map to this code, **not** `invalid_selector`                                                                                                                                                                                                                                                      |
| `node_not_allowed`                     | 1    | the target is a page-shell anchor and cannot be read                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `invalid_selector`                     | 1    | the selector syntax is illegal (`data.reason: "syntax"`), or the selector hits multiple addressable elements and an id is required (`data.reason: "ambiguous"` + `data.count` + `data.matches` + `data.candidates`). `count` is the **total number of candidates in this ambiguity** (equals `addressable` on ambiguous hits; truncation does not affect it; invariant `candidates.length === Math.min(count, 5)`): it is always 2 for a double interpretation (one id + one selector); **not** "how many elements the selector hit" — that number is `matches` |
| `invalid_document`                     | 1    | a companion file such as `hr-meta` is not valid JSON                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `invalid_fragment`                     | 1    | the fragment is empty/whitespace-only, or parses to other than exactly one root element (unbalanced tags are not an error — HTML5 error-tolerant parsing closes them)                                                                                                                                                                                                                                                                                                                                                                                           |
| `invalid_max_bytes`                    | 1    | `maxBytes` is outside `(0, MAX_BYTES_LIMIT]`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `invalid_input`                        | 1    | an argument/config/input violates its contract (includes `hr export` output **> 4 MiB**; judged on the exact UTF-8 byte count after assembly, not an estimate, so 4 MiB±1 cannot take the wrong branch)                                                                                                                                                                                                                                                                                                                                                         |
| `locked`                               | 1    | the concurrent write lock is taken or was taken over                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `forbidden_content`                    | 1    | the content to write contains forbidden items (scripts, external resources, …)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `undo_unavailable` / `nothing_to_undo` | 1    | there is no snapshot to roll back / undo                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `invalid_style` / `unknown_style`      | 1    | the style file is invalid / the `styleId` does not exist                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `invalid_theme`                        | 1    | the theme CSS is illegal (contains `</style>` or external `url()`)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `anchor_lost`                          | 1    | the annotation anchor went stale (that passage was edited)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `file_exists`                          | 1    | the target exists and `--force` was not given                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `not_found`                            | 1    | the entity (e.g. an annotation) does not exist                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `invalid_request` / `invalid_payload`  | 1    | the HTTP request body is not a JSON object / the payload is self-contradictory                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `busy`                                 | 1    | the document is held by another write request                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `too_many_clients`                     | 1    | the SSE client limit is reached                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `unauthorized` / `forbidden_origin`    | 1    | credentials are missing / `Origin` is not in the allowlist                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `chrome_missing`                       | 3    | no local Chrome found (`HREADER_CHROME` and the three candidate paths all miss); the message names the variable and the paths                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `chrome_failed`                        | 3    | Chrome fails to launch / handshake / render, **or Chrome's self-reported artifact size is inconsistent with the request** (a width parasitic on computed values counts as an internal inconsistency → failure, not a user request error)                                                                                                                                                                                                                                                                                                                        |
| `render_timeout`                       | 3    | rendering exceeds `--timeout` (early exit sends `SIGTERM`, `SIGKILL` 2s later; no orphan process remains after exit)                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `render_empty`                         | 3    | the artifact is 0 bytes or structurally invalid (PDF without a `%PDF-` header / PNG without IHDR)                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `path_outside_workspace`               | 3    | the target escapes the workspace                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `not_a_file`                           | 3    | the path does not exist or is not a regular file                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `io_failure` / `style_io_failure`      | 3    | read/write failure (disk, permissions)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `invalid_utf8`                         | 3    | the file is not valid UTF-8                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `llm_failure`                          | 3    | the style-suggestion call failed (keys, prompts, or raw responses must never appear in the message)                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `daemon_already_running`               | 1    | a daemon already holds the port (a runtime state, not a usage error); the message names the pid and the two exits: `kill <pid>` or delete `daemon.json`                                                                                                                                                                                                                                                                                                                                                                                                         |
| `port_in_use`                          | 2    | the `127.0.0.1:<port>` bind genuinely fails (`EADDRINUSE`) and the holder is **not** our daemon (if it were, the previous row applies); also used when the port recorded in `daemon.json` does not answer identity (`/healthz` times out or returns non-JSON) — unreachable ≠ proven ours; the fallback is always picking another `--port`. A separate listener on `::` is only a stderr note and does not decide whether startup succeeds                                                                                                                      |
| `needs_normalize`                      | 2    | the document **lacks** `data-hr-id` (the pre-flight check of `outline`/`read`/`patch`/`serve`); the message names `hr normalize <file> --write` (normalize fills them in — it is "missing", not "colliding")                                                                                                                                                                                                                                                                                                                                                    |
| `duplicate_id`                         | 2    | two elements **share** one `data-hr-id` in the same document (also exit 2; told apart from `needs_normalize` by "missing vs colliding"): `read`/`patch` fail with this code **before locating** — the duplicated spot can never be read, patched, or deleted (it is not "only the first match wins"); the message names `hr normalize <file> --write` (normalize renames the later one)                                                                                                                                                                         |
| `content_model_conflict`               | 2    | the fragment's content model is incompatible with the target container (checked before `patch`'s `append`/`prepend`/`replace` writes): phrasing-only containers like `<p>`/`<h1>`–`<h6>`/`<pre>` cannot hold block-level children. **User-fixable** (pick another container such as `article`/`section`/`div`, or change `--html`), so it stays separate from `invalid_input` (the whole input is illegal → consult the docs) and does not reuse `invalid_fragment` (the fragment itself is legal — it just "does not fit")                                     |

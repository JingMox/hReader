# M2.2 · 阅读器核心界面骨架（`packages/app`）

> 唯一验收依据。依据 `docs/02` §5（左栏书库/TOC、中栏画布、右栏旁注）与其路线图条目，**但不含** M2.3 的批注持久化 / Visual Diff / Undo——那三件是下一张卡。
> 语言与工具约束：**零新增依赖**（用户 2026-11-13 裁定，runtime 与 dev 都算）。因此**不用** Vite / React / Preact / jsdom（`docs/02` 里那句"Vite + Preact"作废，协调者已改文档）。

## 0. 目录与分层（写死，改动要问协调者）

```
packages/app/
  package.json                 # name "@hreader/app", type module, 无 dependencies
  tsconfig.json                # 复用根配置，outDir 到 dist
  src/
    main.ts                    # 入口：读 <body data-*> → boot()
    boot.ts                    # 组装：store ← sse ← widgets，无业务逻辑
    state.ts                   # ReaderState / ReaderIntent（纯类型 + 纯 reducer）
    store.ts                   # createStore(initial) → { get, dispatch, subscribe }
    sse.ts                     # createSse(url, onEvent)（EventSource 可注入）
    dom.ts                     # Host 接口 + createDomHost(document)（唯一碰真实 DOM 的适配器）
    widgets/
      library.ts               # 左栏：文档列表 + TOC 树
      canvas.ts                # 中栏：文档正文 + 浮动控制条
      sidenotes.ts             # 右栏：批注占位（M2.3 才填内容）
      statusbar.ts             # 底部：连接状态 / 版本 / 快捷键提示
    keys.ts                    # 键盘 → Intent（纯函数，输入 KeyboardEventLike）
    style-switch.ts            # 0-token 主题切换：换 <style id="hr-theme"> 的文本
```

**分层规则（depcruise 必须能表达，必要时加规则）**

1. `widgets/**` **不许** import `dom.ts` 的具体实现，只依赖 `Host` 接口与 `state.ts` 类型。
2. `keys.ts`、`state.ts`、`style-switch.ts` 是纯函数模块，**不许**碰 `document`/`window`/`fetch`/`EventSource`。
3. 只有 `main.ts`、`boot.ts`、`dom.ts` 可以引用全局 `document`/`window`/`EventSource`。

## 1. 契约（AC）

### 1.1 静态托管（core 侧，小改）

- **AC1.1** `GET /` 返回 `index.html`（`text/html; charset=utf-8`），其中仅含 `<div id="hr-root">` 与 `<script type="module" src="/assets/main.js">`；**不含内联脚本**（CSP 友好）。
- **AC1.2** `GET /assets/<path>` 返回构建产物；路径穿越（`..`、`%2e%2e`、绝对路径、反斜杠）→ 404 + `path_outside_workspace` 语义等同拒绝，**不许**读到工作区外文件。
- **AC1.3** 未知 `/assets/*` → 404（不是 500）；`HEAD` 未实现则按既有 method 逻辑 405。
- **AC1.4** 静态响应带 `cache-control: no-store`（本地开发优先正确性）与 `x-content-type-options: nosniff`。

### 1.2 状态与渲染

- **AC2.1** `createStore` 只有三个方法 `get/dispatch/subscribe`；`subscribe` 返回退订函数；**相同 state 不重复通知**（reducer 返回同一引用则不通知）。
- **AC2.2** 每个 widget 的契约统一为 `mount(host, parent, state) → { update(state): void }`；`update` 只写有变化的节点（用 `Host` 的 `setText`/`setAttr` 而非重建整棵子树）。
- **AC2.3** 左栏 TOC 由 `GET /api/doc/<docId>/outline` 的 `nodes` 生成，层级按 `level`；点击某条 → 派 `scrollTo(id)`；**当前可见块**（由 `keys.ts` 的 `j/k` 移动后的 `activeId`）在 TOC 中高亮。
- **AC2.4** 中栏正文来自 `GET /s/<docId>?t=<token>` 返回的 HTML，**整体注入一次**（`Host.setHtml`）；此后 `doc.changed` 事件只更新受影响的块（按 `data-hr-id` 定位），**不许整篇重载**（会导致滚动位置丢失）。
- **AC2.5** 右栏在 M2.2 只显示"本章有 N 条批注（M2.3 启用）"占位的静态文案；**不许**伪造批注数据。
- **AC2.6** 三栏布局：`grid-template-columns: 280px minmax(0, 1fr) 280px`；中栏正文 `max-width: 68ch`；`@media (max-width: 1100px)` 折点为两栏（书库折叠为抽屉）；`min-width: 0` 与 `overflow-wrap: anywhere` 必须在栅格子项上（防长 URL 撑破）。

### 1.3 键盘流

- **AC3.1** `j`/`k` 在 `[data-hr-id]` 块间移动 `activeId`（按文档顺序，到头不循环）；`h` 切换 `focus` 高亮；`c` 派 `openSidenote(activeId)`（M2.2 只打开空面板）；`/` 聚焦搜索框；`Esc` 关闭面板。
- **AC3.2** 焦点在 `input`/`textarea`/`[contenteditable]` 时**不**触发单键快捷键。
- **AC3.3** `keys.ts` 是纯函数：`(event: KeyLike, state: ReaderState) → ReaderIntent | undefined`，**不读 `document`**；`KeyLike` 只含 `key`、`metaKey`、`ctrlKey`、`altKey`、`target` 的标签名。

### 1.4 同步（SSE）

- **AC4.1** `createSse` 消费 `/api/events`；事件类型 `doc.changed` / `library.changed` / 自定义心跳注释帧**都要**容忍（未知类型忽略）。
- **AC4.2** 断线 → 指数退避（1s 起，×2，上限 30s）+ 抖动；连上后重置；退避期间状态栏显示 `reconnecting`。
- **AC4.3** `doc.changed` 的 `revision` 落后于本地已显示版本时**丢弃**（防乱序覆盖）。

### 1.5 主题（0-token 切换）

- **AC5.1** 控制条下拉列出内置主题（至少 `atelier-editorial`），选择后**只**替换 `<style id="hr-theme">` 的 `textContent`；不重载页面、不丢滚动位置。
- **AC5.2** 主题 CSS 来自 `GET /api/theme/<id>`（core 侧新增，读内置主题；未知 id → 404 `unknown_style`）。**不许**把 CSS 内联进 JS 字符串。

## 2. 预设裁定（别再来问）

1. **不做虚拟 DOM、不做 diff 算法**：widget 自己维护 `update`，只改该改的节点。理由：本 UI 的数据形状固定（三栏 + 一篇文章），通用 diff 是负资产。
2. **不引入任何动画/过渡**（`transition` 仅允许 `color`/`background` 100ms）。
3. **`innerHTML` 只允许两处**：`AC2.4` 的正文注入与 `index.html` 的一次性骨架；其余一律 `createElement`/`setText`。
4. 事件处理一律 `addEventListener` + 显式解绑（`destroy()` 返回或 `AbortController`），**不许** DOM 上挂自定义属性存状态。
5. 所有用户可见文案用**中文**，代码标识符用英文；文案集中在 `widgets/copy.ts`（便于以后 i18n，不许散落）。
6. 构建：`tsc -p packages/app` 输出 `dist/*.js`（ESM，无打包）；`hr serve` 通过 `--app-dir` 指向该目录，缺省 `packages/app/dist`。
7. 无 bundler ⇒ **无 tree-shaking**，所以 `src/` 里不许有"只在测试用"的导出（死代码即 P1）。测试需要内部结构时按既有先例用 `@internal` 导出。
8. 图标用**文字/Unicode**（`📌`、`✨`），不引入图标库。

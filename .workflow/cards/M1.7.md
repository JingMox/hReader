# M1.7 · `Atelier Editorial` 主题包 + `hr_apply_style`

> 依据：`docs/05-feature-cards.md` §M1.7（AC1–AC6）、`docs/02:44-60`（风格包仓库结构）、`docs/02:120-150`（视觉法则、组件语义）。
> 本卡是**唯一产出 CSS 资产**的卡：核心 API 只做"标签替换"，不做布局计算。

## 0. 分层

| 层 | 路径 | 职责 |
|---|---|---|
| 资产 | `styles/atelier-editorial/theme.css` | 唯一的主题 CSS（含双模、组件、打印） |
| 纯变换 | `src/style/apply.ts` | 字符串级替换 `<style id="hr-theme">` |
| 适配 | `src/io/themeStore.ts` | 从 `themesRoot/<id>/theme.css` 读 CSS（经 `FileSystem` 端口） |
| 编排 | `src/io/applyStyleFile.ts` | 锁 + 备份 + 原子写（复用 M1.5 的 `atomic`/`history`/`lock`，不复制） |

- `apply.ts` 不得 import `node:fs`，也不得 import `io/**`（depcruise 断言方向）。
- **复用**原则：`applyStyleFile` 必须调用 M1.5 的 `writeAtomic`/`pushHistory`/`withFileLock` 三个函数，不许再写一份 rename/备份逻辑（审计按此判 P1）。

## 1. 核心 API

```ts
applyStyle(html: string, input: { themeCss: string }): string
loadTheme(input: { themesRoot: string; visualId: string }, deps: { fs: FileSystem }): Promise<string>
applyStyleFile(input: { workspace: string; file: string; themesRoot: string; visualId: string }, deps: ApplyStyleDeps): Promise<ApplyStyleResult>
type ApplyStyleResult = { path: string; bytes: number; historyPath: string | null; changed: boolean };
```

`applyStyle` 规则：
1. 文档中出现 `<style id="hr-theme">`（属性顺序任意、单双引号任意）→ **只替换其文本内容**，标签与其余属性原样保留。
2. 出现**多个** `<style id="hr-theme">` → `HrError("invalid_document")`（不确定该替换哪个，拒绝猜测）。
3. 不存在 → 在 `<article>` 的**第一个子节点位置**插入 `<style id="hr-theme">\n<css>\n</style>`；无 `<article>` → `HrError("no_article")`。
4. **除该节点外，输出与输入逐字节相同**（AC4 的"0 Token 换肤"）：`hr-meta`、正文 DOM、注释、空白、属性顺序全部不动。实现方式：复用序列化器的"未变更子树原样输出"，不许整篇重新格式化。
5. 幂等：同一 `themeCss` 连续应用两次，第二次输出与第一次逐字节相同（`changed: false` 时不写盘、不留历史）。
6. `themeCss` 为空串或只含空白 → `HrError("invalid_input")`；`themeCss` 内出现 `</style`（大小写不敏感）→ `HrError("forbidden_content")`（防提前闭合。

## 2. 主题资产（`styles/atelier-editorial/theme.css`）

### 2.1 令牌（AC1）
必须定义且仅在 `:root` 定义一次：`--hr-bg`、`--hr-fg`、`--hr-accent`、`--hr-muted`、`--hr-border`、`--hr-code-bg`、`--hr-font-body`、`--hr-font-mono`、`--hr-measure`、`--hr-sidebar`。

- 默认（日间）与夜间两套值：`@media (prefers-color-scheme: dark)` **与** `[data-hr-mode="dark"]` 都要能覆盖（前者跟系统、后者被阅读器强制）；`[data-hr-mode="light"]` 反向覆盖。
- 对比度：`--hr-fg` on `--hr-bg`、`--hr-muted` on `--hr-bg` 的 WCAG 对比度 **≥ 7:1**（AAA）。测试用纯函数算相对亮度（公式写进测试夹具，不引依赖），CSS 里的十六进制值由测试解析，**不许**在测试里重复硬编码同一串颜色。

### 2.2 布局（AC2）
- 正文容器 `max-width: var(--hr-measure)`，`--hr-measure: 68ch`。
- 侧边栏 280px：`grid-template-columns: minmax(0, 1fr) 280px`，`@media (max-width: 900px)` 塌成单列。
- 320px 视宽无横向滚动：所有 `width`/`min-width` 字面量 ≤ 320px，或用 `minmax(0, 1fr)`/`100%`；**禁止** `overflow-x: hidden` 掩盖问题（用 `grep` 断言不存在）。

### 2.3 组件（AC3，7 个选择器）
`[data-hr-block="kpi-bento"]`、`[data-hr-block="callout-insight"]`、`[data-hr-block="callout-warning"]`、`[data-hr-block="split-compare"]`、`[data-hr-block="deep-dive"]`、`[data-hr-block="step-timeline"]`、`[data-hr-block="diagram-stage"]` —— 七个各至少一条规则，且必须"语义上可区分"（不是同一个装饰换名字）：测试断言七者至少产生 **5 种不同的声明组合**。

### 2.4 打印（AC6）
`@media print` 必须：隐藏 `[data-hr-chrome]`（交互控件）、`page-break-inside: avoid` 作用于 `[data-hr-block]`、保留 `a[href^="#"]` 的锚点文本（内容不丢）。

### 2.5 离线（AC5）
- 禁止 `@import`、`@font-face`、`url(http`、`url(//`、`<img>`、`data:image` 之外的外链（`grep` 断言）。
- 只允许系统字体栈（`--hr-font-body` 以 `system-ui` 开头）。

## 3. 加载与错误

- `visualId` 校验同 M1.6 的 `invalid_style_id` 规则（先校验正则，再拼路径）。
- 主题目录不存在或 `theme.css` 缺失 → `HrError("style_not_found")`。
- `applyStyleFile` 的写路径安全、锁、备份、undo 全部复用 M1.5 已验收的语义，**不得**推翻（例如不许为了"只换 CSS"而绕过备份）。

## 4. 新增错误码

**无新增**。复用 `invalid_document`、`no_article`、`invalid_input`、`forbidden_content`、`style_not_found`、`invalid_style_id`、`locked`、`io_failure`、`undo_unavailable`。

## 5. 非目标

- 不做阅读器前端（M2）。
- 不做主题市场/多主题（M1 只交付 `atelier-editorial` 一套）。
- 不做 CSS 压缩/构建（资产原样发布，`prettier` 不管 `styles/**`，在 `.prettierignore` 里排除并说明）。
- 不做浏览器端 E2E（本卡只做结构断言 + 一次人工浏览器核对，见门禁 6）。

## 6. 门禁（本卡额外）

1. `pnpm verify` EXIT=0，四维 100%。
2. **0-Token 换肤**：对 `packages/core/fixtures/**` 里最大的一份真实文档（≥10KB）跑 `applyStyle`，断言"除了 style 节点文本外逐字节相同"——用 `diff` 定位差异区间必须完全落在 `[<style ...>, </style>]` 内。
3. **幂等**：连跑两次，第二次 `changed=false`；磁盘 mtime 不变（用注入的 `clock` 与真实写各测一次）。
4. **`</style` 注入**：`themeCss` 含 `</style><script>` → `forbidden_content`，文件不被修改。
5. **令牌/对比度**：CSS 解析断言 10 个令牌齐全、7 个组件选择器齐全、AAA 对比度成立、无 `@import`/`url(http`/`overflow-x: hidden`。
6. **人工核对**（诚实降级）：`styles/atelier-editorial/sample.html` 用无头浏览器（`node --experimental-strip-types` + 无依赖截图不可行时，改为**结构性断言 + 报告里记录人工核对结论**），在 320px/768px/1440px 三档截图存档到 `.workflow/assets/M1.7/`，报告里写"哪些 AC 是结构断言、哪些是人工确认"。**不许**声称"已验证无横向滚动"而不给依据。
7. 变异体 ≥5（含：只替换不保留属性顺序、插入位置改成 body 末尾、幂等靠 sha 比较而非 changed、编辑器样式多插一个换行、对比度断言被写成恒真）。

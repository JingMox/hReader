## §2 决策与裁定（D1–D12，写者不得改动）

- **D1 产物 = 单文件自包含 HTML，不是 PDF 二进制**。`hr export print <src> --out <path> --visual <id>` 产出一个 `.html`：内联主题 CSS + 内联打印规则、零 `<script>`、零外部**资源**引用（无 `<link>`、无 `src=` 外链、无 `@import`、无 `url(http…)`）。正文里的 `<a href="https://…">` **保留**（超链接是内容，不是资源加载），纸面 URL 靠 `::after` 括注。
  - 理由：真 PDF 需 Playwright/headless Chrome（~300 MB）或 WeasyPrint（Python 工具链）；本卡**自查不需要**任何新依赖即可交货（注意：仓库级"零新依赖"策略已于 §10.10 废止，本卡只是自己不需要）。PDF 二进制与长图另立 M4.4 调研卡（§5）。
- **D2 确定性：同输入 + 同主题 → 字节相同**。产物禁出现时间、随机串、`process.cwd()`、主机名、绝对路径。元信息只放 `<meta name="hr-doc-id">`（= 源文件 basename 去扩展名）与 `<meta name="hr-visual">`。
  - **主题解析必须 workspace 域内**（D7 加固）：`hr export print` **不读** `~/.hreader/styles`，否则同一 `--visual` 换机器换字节。这条是 AC-3 的前提。
- **D3 纯函数在 `packages/renderer-html`，I/O 在 cli**。包内禁 `node:fs`/`node:path`/`process`（depcruise 兜住，AC-9）。
- **D4 打印样式 = TS 常量**：`packages/renderer-html/src/print-css.ts` 的 `export const PRINT_CSS: string`；不新建 `assets/*.css`（本仓 ESM 构建不处理 CSS 资产，`cpSync` 那条链是已登记历史债 `L-21`）。
- **D5 编号与 TOC 只从 outline 派生一次**：用 `buildOutline(parsed)` 的 `OutlineNode[]`。**注意 `buildOutline` 会收非 heading 节点**（`section`/`header`，见 `core/src/ops/outline/constants.ts:6`，`:47` 注释"无标题则继承父级、顶层记 0"），且 `h5/h6` 被 `OUTLINE_DEPTH_LIMIT` 排除（`core/src/ops/outline/walk.ts:200`）。因此：
  - **编号只由 `tag` 为 `h1`–`h4` 的节点决定，容器节点不参与编号**；
  - 层级自增用节点的 `level`（1–4），**不用树深**；
  - 越级（h2 → h4）按"父层号 + 末位自增"记 `1.1.1`，不补空槽；`level=0` 的容器不产生编号。
- **D6 复用主题既有类名**：正文用 `data-hr-component`/`data-hr-id`（core 注入）、TOC 用 `toc__item`/`toc__item--h<level>`/`data-toc-id`，使 `theme.css` 既有规则不改一字即可作用于打印稿。**注意**：`.hr-sidebar` 等在 app 侧不存在（§1），D9 的裁切清单是"防御性清单"，不是"既定契约"。
- **D7 主题读取走 core**：`loadThemeCss(themeDepsOf(workspace))`（`core/src/style/theme.ts:24`）+ `assertThemeSafe`（`core/src/style/css.ts:69`）；**禁止** cli 直接读 `packages/mcp-server/src/styleDeps.ts`（那会新增 `cli→mcp-server` 跨包边、复制候选链、并绕过安全闸——真 XSS 面）。workspace 域：`{ workspaceRoot }`，不含 `deps.home`。
- **D8 `--visual <id>` 必填**，无默认、无猜测。
- **D9 交互/危险面在渲染层裁掉**（不是 CSS 隐藏）：`<script>`、`<style>`（源文档里的）、`<button>`、`<input>`、`<form>`、`contenteditable`、`.hr-sidebar`、`.hr-toc-toggle`、`.hr-mode-toggle`、`[data-hr-ui]`、以及**所有 `on*=` 事件属性**、`href`/`src` 的 `javascript:`/`data:text/html` 协议。裁后正文无文本 → `HrError("empty_document")`，**不写盘**（见 D10 与 AC-11）。
- **D10 覆盖与原子写**：`--out` 已存在且无 `--force` → `HrError("invalid_input")`（文案含"加 --force 覆盖"）；写盘用 core 的 `writeAtomic`（`core/src/io/atomic.ts:102`）——**F3 需把它从 `core/src/io/index.ts` 与 `core/src/index.ts` 极小导出**（记入 `docs/02` §5.2 极小导出面 + `docs/05`）。禁自己 `writeFileSync`。
- **D11 真浏览器验证 = 交付前置，不是 CI 必过项**：`pnpm verify` 只跑无浏览器断言；`scripts/print-e2e.ts` 用真 Chrome 验 AC-6 每条规则。**本机有 Chrome（§1），故结卡前必须有真跑记录贴进测试报告**；无 Chrome 的机器打印 `SKIP: chrome not found` + 安装命令 + 退出 0，但**此时测试员不得签核 AC-6**（`docs/03` §11.22 SKIP 假绿形态）。
- **D12 `--json` 走既有信封**：`{"ok":true,"data":{"out":"<绝对路径>","bytes":<n>,"sections":<n>,"visual":"<id>"}}`，`bytes` 必须与 `statSync().size` 相等（测试交叉核对，别信渲染层 buffer 长度）。无 `kind` 键。

## §3 验收标准（AC-1…AC-13）

- **AC-1 闭环**：`hr export print packages/renderer-html/tests/fixtures/article.html --visual atelier-editorial --out /tmp/p.html` 退出 0，文件完整；`open` 后 `⌘P` 预览可见封面/TOC/正文三段。**fixture 由 F1 创建**（`docs/demo.html` 不存在，§1）。
- **AC-2 自包含（检查面写死）**：产物中 `<script`=0、`<link`=0、`@import`=0、`src="http`/`src="//`=0、`url(http`=0、`<iframe`=0。**正文 `<a href="http…">` 不算违规**（内容超链接）。测试用**含外链的 fixture** 与 **纯本地 fixture** 各一。
- **AC-3 确定**：同参数连跑两次同 `shasum`；换 cwd 同 `shasum`；**换 `HOME`**（`HOME=/tmp/emptyhome`）同 `shasum`（证 D2+D7 不读用户目录）。
- **AC-4 结构计数**：产物含且仅含一个 `<article>`；`<section class="chapter">` 数 = outline 中**非 heading 容器**数；标题计数用"outline 里 `tag` 匹配 `^h[1-6]$` 的节点数"对照产物 `<h1..h6>` 数（**不得**用 outline 节点总数，§2 D5）。每个标题带稳定 `id="sec-<n>"`，TOC `href` 与之**双向逐条对应**。
- **AC-5 编号**：`1`/`1.1`/`1.1.1` 按 D5 口径；h2 跳 h4 记 `1.1.1`；h5/h6 不进 TOC；**同名标题两次出现**产生不同 `id`/`data-toc-id`（按序自增，不冲突）。
- **AC-6 出版级规则**（`PRINT_CSS` 至少覆盖，且**每条**在真 Chrome 里行为符合）：`@page{size:A4;margin:20mm 18mm}`；`@page:first` 无边距；`h1..h4{break-after:avoid}`；`thead{display:table-header-group}`；`tr,img,figure,table{break-inside:avoid}`；`p{widows:3;orphans:3}`；`a[href^="http"]::after{content:" (" attr(href) ")"}`；`pre,code{white-space:pre-wrap;overflow-wrap:anywhere}`；`section.chapter{break-before:page}`；封面 `break-after:page`、TOC `break-after:page`；`@media print{:root{color-scheme:light}}` + 深色变量覆盖。
- **AC-7 裁切**：fixture 各塞 `<button>`/`<script>`/`<style>`/`.hr-sidebar`/`[data-hr-ui]`/`onclick=`/`href="javascript:"` 各一 → 产物里**解析后**计数为 0（用 `parseHtml`，不 grep 字符串）。
- **AC-8 错误码**：`--visual` 缺失 → `invalid_input`；未知 visual → `unknown_style`（core 既有）；`--out` 已存在无 `--force` → `invalid_input`；越出 workspace → `path_outside_workspace`；主题读失败 → `style_io_failure`；主题含逃逸 → `invalid_theme`（`assertThemeSafe` 既有）；**新码 `empty_document`**（需加进 `core/src/hr-error.ts` + `packages/cli/src/exit-codes.ts` 穷尽表 + `docs/05` 错误表）。
- **AC-9 依赖边界**：depcruise 断言 `renderer-html` 不 import `node:*`、不 import `cli`/`app`/`mcp-server`；knip 静默（新包 exports 真被消费；新脚本是 `.ts` 且进 `knip.json` 可见路径）。
- **AC-10 覆盖率**：`packages/renderer-html/src/**` 与 `packages/cli/src/commands/exportPrint.ts` perFile 四维 100%，全仓不退（测试员报新基线）。
- **AC-11 边界±1 三态**（§10.8）：空 `article`（→ `empty_document` 且目标文件**不存在**）；纯标题无正文（**不许** `empty_document`）；产物上限 4 MiB 的 `limit-1` 产出 / `limit+1` 报 `invalid_input`。
- **AC-12 `data-hr-id` 幂等**：源文档已带合法 `data-hr-id` 必须逐字保留（core `html/inject.ts:121-123`）；非法值被改写并留诊断（照既有行为，不新造）。
- **AC-13 主题注入安全**：含 `</style>` 与 `url(http://…)` 的主题 fixture → `invalid_theme`，且即使强行渲染产物 `<script`=0（`assertThemeSafe` 不可绕过，D7）。

## §4 钉子

- `styles/atelier-editorial/theme.css`：**只增不改**，只在文件末尾追加 `@media print` 块；既有 244 行删除行数必须为 0（`git diff` 可断言）。
- 产物 `<style>` 顺序：主题在前、`PRINT_CSS` 在后（测试断言 index 先后）。
- `PRINT_CSS` ≤ 8 KiB；单文件产物 ≤ 4 MiB。
- 命令名 `export print`（`hr export print`）。
- 产物根 `<html lang="zh-CN">`。
- 封面标题来源优先级（v1 缺失，v2 裁定）：`<title>` 文本 → 首个 `h1` 文本 → 源文件 basename 去扩展名。

## §6 假绿形态

1. **规则存在 ≠ 规则生效**：断言 `PRINT_CSS` 含 `widows:3` 很容易过，选择器写错也过。"存在"由单测钉，"生效"必须真 Chrome（D11/AC-6）。
2. **`--json` 只测 happy path**：`bytes` 与 `statSync().size` 交叉核对（D12）。
3. **确定性偷懒**：只同 cwd 跑两次 → 过；必须换 cwd **且**换 `HOME`（AC-3）。
4. **裁切断言太弱**：`not.toContain("<button")` 会放过 `<BUtton>`/`<button/>`；用 `parseHtml` 数节点（AC-7）。
5. **靠 CSS 隐藏冒充裁切**：断言"节点不在 DOM"，不是 `display:none`。
6. **TOC 双向只测一边**：只断"项数=标题数"会放过 href/id 全错。
7. **SKIP 假绿**：无 Chrome 时 AC-6 不得签核（D11）。

## §11 v3 裁定（2026-11-17，测试员第 7 代 AC 矩阵提的歧义，协调者逐条裁定；**以本节为准**）

## §12 v4 裁定（F1 审计后，2026-11-17）

1. **`empty_document` 是文本级判据**：裁切 → 序列化 → **去掉全部标签与空白**后为空才报。（`<article><section></section></article>`、只含内联图无文字的文档都报；空 section 不许渲染成空 chapter 蒙混过去。）实现用 `parseHtml` 走文本节点累加，不用正则剥标签。

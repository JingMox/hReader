**G1（SURVIVED ⑩ / 用户可见）换文档后状态行仍报旧风格**
文件：`packages/pi-extension/tests/style-command.test.ts`（挂在现有 `describe("/hr-style 落盘")` 后）

```ts
it("换到另一个文档后，状态行不再报上一个文档的风格", async () => {
  // Arrange：daemon 报两个可选风格，POST /api/style 成功
  const harness = harnessOf((url) =>
    url.includes("/api/theme")
      ? themeReply(["feynman-tech", "atelier-editorial"])
      : url.includes("/api/style")
        ? styled()
        : hung(),
  );
  await harness.run("hreader", "docs/a.html");
  await harness.run("hr-style", "feynman-tech");
  // Act：绑定另一个文档，再看状态行
  await harness.run("hreader", "docs/b.html");
  await harness.run("hreader", "");
  // Assert：docs/b.html 没换过风格，状态行不得带 `风格 feynman-tech`
  expect(harness.notifies.at(-1)?.message).not.toContain("风格 feynman-tech");
});
```
**实测当前红**（`av4.ts`）：notify 尾部 = `…workspace /work，风格 feynman-tech`。修法二选一：绑定新文档时 `session.themeId = undefined`，或状态行只在 `themeId !== undefined && docId === 上次换风格的那个 docId` 时才拼。**先定语义再写用例**，别让用例单方面定产品。

**G4（AV-D / 用户可见）两次 `/hr-style` 并发，慢响覆盖后一次的结果**
文件：`packages/pi-extension/tests/style-command.test.ts`

```ts
it("后一次 /hr-style 的结果不被前一次的慢响覆盖", async () => {
  // Arrange：第一次 POST 延迟 150ms，第二次延迟 10ms，两次都 changed:true
  let styleIndex = 0;
  const harness = harnessOf((url) => {
    if (url.includes("/api/theme")) return themeReply(["feynman-tech", "atelier-editorial"]);
    if (url.includes("/api/style")) {
      const delay = styleIndex === 0 ? 150 : 10;
      styleIndex += 1;
      return sleep(delay).then(() => styled());
    }
    return hung();
  });
  await harness.run("hreader", "docs/x.html");
  // Act：第二条命令在第一条 POST 还没 settle 时发出
  const first = harness.run("hr-style", "feynman-tech");
  await sleep(5);
  const second = harness.run("hr-style", "atelier-editorial");
  await Promise.all([first, second]);
  await harness.run("hreader", "");
  // Assert：最终状态必须是后发那条
  expect(harness.notifies.at(-1)?.message).toContain("风格 atelier-editorial");
  expect(harness.notifies.map((entry) => entry.message).at(-3)).toContain("atelier-editorial");
});
```
**实测当前红**：最终 `风格 feynman-tech`，notify 顺序倒置。修法：命令入场记 `const token = ++session.styleSeq`，`await` 回来只在 `token === session.styleSeq` 时才写 `themeId`/发「已换成」；否则只静默（或报「已被更晚的选择覆盖」）。

it("GET /api/theme 慢时，被取代的那条命令连 POST 都不发（不只丢结果）", async () => {
  // Arrange：第一次 GET 慢 150ms，第二次 10ms（daemon 卡一下就是这个形状）。
  const harness = harnessOf({
    "/api/theme": [{ ...THEMES, waitMs: 150 }, THEMES],
    "/api/style": [STYLED],
    "/api/events": [EVENTS],
  });
  await harness.run("hreader", "docs/x.html");
  // Act：先发 feynman-tech（卡在 GET），5ms 后发 atelier-editorial。
  await Promise.all([
    harness.run("hr-style", "feynman-tech"),
    sleepOf(5).then(() => harness.run("hr-style", "atelier-editorial")),
  ]);
  // Assert：只有后发那条落在 daemon 上；被打断的那条不得发 POST（否则盘上风格与状态行分叉）。
  expect(postsOf(harness, "/api/style").map((request) => request.body)).toEqual([
    JSON.stringify({ docId: "docs/x.html", visualId: "atelier-editorial" }),
  ]);
});
